# Dr. V. P. Jha — Mathematics, Books & Notes

A publication-ready personal website for Dr. Vishwa Prakash Jha, centred on books, visual mathematics notes, and academic work.

## Included

- Interactive mathematical home page
- Searchable and filterable blog library
- Dedicated article pages with reading progress and table of contents
- Dark/light reading themes and responsive mobile navigation
- Books and About pages
- RSS feed, sitemap, robots file, web manifest, and custom 404 page
- Automated GitHub Pages publishing workflow

## Work locally

Open `index.html` directly. To validate and prepare the publishing output:

```bash
npm run check
npm run build
```

The complete publishable website is written to `dist/`. See `BLOGGING_GUIDE.md` for the repeatable post-publishing workflow.
